## M2.2 — Light/Dark/System Theme System

Status: TECHNICALLY GREEN. Manual visual review remains PENDING MAINTAINER.

### Implemented contract

- Locale is URL-driven only: `/` remains Spanish and `/en/` is the single English Home counterpart. `html[lang]` is exact per route; no locale storage, redirect, geolocation, flags, framework, or i18n dependency exists.
- `SiteHeader` supplies a compact 48×34px retro locale plate: real `ES`-left and `EN`-right anchors retain URL-driven `aria-current="page"`; an inset cyan route marker provides the secondary non-color current cue. Desktop explicitly sequences RLP → primary navigation → utilities with a normal flex gap; the centered utility row is locale → theme (and locale → theme → Menu on mobile), with no flags or stored locale state.
- English Home reuses the semantic Home/CMD presentation and translates only its bounded identity copy and actions. Its Header exposes only real progressive counterparts: English Home and the existing Spanish Blog; no future English routes or placeholders are emitted.
- Preference and effective theme are separate: `system`, `light`, or `dark` is stored as `rlp-theme`; absent or invalid storage safely resolves to `system`.
- `html` is the single authority with `data-theme-preference` and effective `data-theme`; synchronous defensive head bootstrap applies stored Dark before the first render and sets `color-scheme`.
- System follows `matchMedia("(prefers-color-scheme: dark)")` live; explicit Light and Dark ignore system changes.
- Semantic theme roles are `--theme-canvas`, `--theme-surface`, `--theme-surface-raised`, `--theme-text`, `--theme-text-muted`, `--theme-line`, and `--theme-accent`. Light maps to the canonical Paper/Ink direction. Dark exact values are canvas `#1C1D1D`, surface `#242525`, raised surface `#2D2E2E`, text `#F2F0EA`, muted `#B8B7B0`, line `#85857E`, and accent `#5CB6C3`.
- Superseding the button/select/radio presentations, one native Header `input[type="range"]` is the semantic owner of the compact retro inline SVG switch: `min="0" max="2" step="1"` maps System left (`0`), Light center (`1`), and Dark right (`2`). Its Spanish name and value text expose the stored preference, not the effective theme; direct range selection plus native Arrow Left/Right and Home/End behavior update it. The SVG is `aria-hidden`; visible focus plus desktop/mobile utility placement remain.
- CMD remains fixed at Terminal `#0C0C0C`; Home and established Blog index/article routes adopt semantic colors without structural redesign.
