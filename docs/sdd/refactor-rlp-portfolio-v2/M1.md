## M1.2 — Design Decision Promotion

Status: COMPLETE

Exploration decisions promoted to the normative doctrine:

- IBM Plex Sans is the editorial and UI family; IBM Plex Mono is technical system and evidence context only.
- `SiteHeader` is the sole navigation contract with RLP identity, semantic current state, bilingual access, and responsive content-fit behavior.
- Home is intentionally short and routes own their complete territory content.
- Primary, Secondary, and Text/Action Link establish the canonical action hierarchy.
- Surface grammar is semantic: common Surface, Artifact, Dossier, Record, and Explorer; universal generic Cards are prohibited.
- Hero CMD is bounded RLP identity chrome, not fabricated runtime activity.
- Responsive Home preserves semantic content from 320px through >=1024px while decorative chrome may adapt.
- Territory grammars define Home, Work, Production, Experience, Education, Notes, About, and Contact; evidence is real or omitted.
- Token intent families establish names only; M1.3 resolves implementation metrics and values.
- `Engineered, not generated.` remains an internal principle, never a footer slogan or public headline.

M1.2 is decision-evidence only. It establishes no production tokens, source changes, or implementation routing.
